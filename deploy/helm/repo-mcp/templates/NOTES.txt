Configure it. Squads, roles, connectors and the identity settings live in the
database, not in this chart — set them once, for this environment:

  curl -s localhost:{{ .Values.gateway.service.port }}/admin/login \
    -H 'Content-Type: application/json' \
    -d '{"username":"{{ .Values.migrations.adminUsername }}","password":"..."}'

Start the first discovery pass once a connector exists:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "repo-mcp.fullname" . }}-indexer {{ .Values.indexer.service.port }}
  curl -X POST localhost:{{ .Values.indexer.service.port }}/rescan -H "Authorization: Bearer $CI_TRIGGER_TOKEN"
