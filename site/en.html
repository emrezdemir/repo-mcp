Every repository you own, as one code graph.

repo-mcp indexes your GitHub, GitLab and Bitbucket repositories centrally and exposes the resulting code graph over MCP to coding agents, chatbots and CI. It is self-hosted and enforces squad-level isolation.

Why repo-mcp

Code intelligence at organisation scale, not one laptop

CENTRAL INDEXING

Index once, everyone uses it

One connector covers a whole organisation; repositories added later join on the next scan, with no configuration change.

SQUAD ISOLATION

Three independent layers

A squad sees its own code in detail and other squads' only as topology. A gap in one layer does not open the others.

ANSWERS FROM THE GRAPH

Evidence, not a guess

ask_codebase runs the graph query first and lets the model interpret only what it returned, citing the symbols by source.

SELF-HOSTED

No restart

Configuration lives in PostgreSQL; every change reaches the services through a counter. Nothing per-deployment lives in git.

The interface

Somewhere to look at the graph

The engine's own interface (React and Three.js, MIT) was adopted and pointed at this platform. Every question about the code goes to /mcp with the caller's own token — anything a browser can do, an MCP client can too.

Get started

Up in five minutes

Docker Engine 24+ and Compose v2 is all it needs. The interface is then at http://localhost:8080/ui. Installation, the roles, and the reasoning behind each decision are in the docs. 

git clone https://github.com/emrezdemir/repo-mcp
cd repo-mcp && make setup   # five questions -> deploy/.env
make up                     # schema, first administrator, services
