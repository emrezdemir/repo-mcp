Bütün repo'larınız tek bir kod graph'ında.

repo-mcp; GitHub, GitLab ve Bitbucket'taki repo'larınızı merkezî olarak indeksler ve çıkan kod graph'ını MCP üzerinden coding agent'lara, chatbot'lara ve CI'a açar. Kendi sunucunuzda çalışır, takım bazlı izolasyon sağlar.

kendi sunucunuzda MCP / JSON-RPC OIDC + LDAP takım bazlı izolasyon MIT

KENDİ SUNUCUNUZDA

Restart yok

Yapılandırma PostgreSQL'de; her değişiklik bir sayaç üzerinden servislere anında ulaşır. Dağıtıma özel hiçbir şey git'te tutulmaz.

Arayüz

Graph'ı gözle inceleyebileceğiniz arayüz

Motorun kendi arayüzü (React + Three.js, MIT) bu platforma bağlandı. Kod hakkındaki her soru kullanıcının kendi token'ıyla /mcp'ye gider — tarayıcının yapabildiğini bir MCP istemcisi de yapabilir.

Başlayın

Beş dakikada ayağa kalkar

Docker Engine 24+ ve Compose v2 (ya da Podman) yeterli. Ardından arayüz http://localhost:8080/ui adresinde. Kurulum, roller ve kararların gerekçesi belgelerde. 

git clone https://github.com/emrezdemir/repo-mcp
cd repo-mcp && make setup   # beş soru -> deploy/.env
make up                     # şema ve servisler; admini /ui'da oluştur
